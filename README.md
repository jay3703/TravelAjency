# ✈️ Travel Agency Web Application

A full-stack **Travel Agency Web Application** built using **Node.js, Express.js, EJS, JavaScript, CSS, and MySQL**.

The application provides a web-based platform for managing travel-related information and services with dynamic pages and database integration.

## 🚀 Features

* 🌍 Travel agency website
* 🏠 Dynamic home page
* 📍 Travel destinations and information
* 📝 Dynamic web pages using EJS
* 🔐 Admin-related functionality
* 🗄️ MySQL database integration
* 🛣️ Express.js routing
* 🎨 Responsive frontend design
* 📦 NPM-based project setup

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/jay3703/TravelAjency.git
```

### 2. Navigate to the project folder

```bash
cd TravelAjency
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure MySQL

Create a MySQL database and import the provided SQL file:

```text
travel_agency (1).sql
```

Update the database connection details in:

```text
conn.js
```

### 5. Start the application

```bash
npm start
```

If the project uses nodemon:

```bash
npm run dev
```

### 6. Open in browser

```text
http://localhost:3000
```
